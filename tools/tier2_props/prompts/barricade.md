## ⚠ THIS PROP IS A FAMILY FROM ROUND ONE, NOT A SPRITE

**§8.3.1 is settled law and it reaches this prop by a route other than tiling.** The trap is *an
incident baked into an asset that then repeats*; a barricade repeats **along a line** by
construction, so it is judged AS LAID exactly as a tile is. One sprite stamped four times along a
corridor is a motif, and the identity card says so: *"a variant family from round one, never a
single sprite."*

So wave 1 generates **four variants of the same construction**, not four candidates for one slot.
The screening question is not *which is best* but *do these four read as four repairs by the same
hands* — §8.3.1's continuity test.

## The prompt, per variant

A shared stem, with the variant clause appended:

> **stem:** barricade section built from salvaged timber lashed with rope and driven iron pins,
> crude and over-built, repairs nailed over older repairs, planks of different ages, grey-brown
> weathered wood and rusted iron, functional not decorative, no ornament, matte, unlit

| variant | appended |
|---|---|
| A | `, uprights braced with a diagonal timber` |
| B | `, a horizontal cross-beam bound at both ends` |
| C | `, a patched gap filled with shorter offcuts` |
| D | `, leaning slightly, propped from behind` |

## Parameters, and the clause each answers

Identical to B-PROP-001 and for the same reasons: `high top-down` (**§3**, ratified),
`lineless` (**§12.1**, no baked ring), `flat shading` (**§6.3**, authored to receive),
`medium detail` (**§4.3** at 32px), 32 × 32.

## Load-bearing clauses

1. **No baked outline** (§12.1), **no baked highlight** (§6.3) — as B-PROP-001.
2. **Every fastening holds something** (§7.3). A rope that wraps nothing is ornament.
3. **The four read as one hand** (§8.3.1's continuity test). Different repairs, same grammar,
   same materials, same competence. Four *styles* fails this as surely as four copies does.
4. **It reads as BUILT, not as debris** (§7.1 — *show me what holds this together*). The
   identity card's `role_reject` names "a pile of debris" for exactly this.
5. **It stands against walls** — the card asks how it sits in the §6.5 stack, so the round
   reports its delivered value against the wall face beside it.
